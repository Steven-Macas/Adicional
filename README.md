## Overview

A collection of smaller projects and exercises from my training.

| Path | Description |
| --- | --- |
| `tienda/` | Online shop in **PHP** + MySQL with product categories (T-shirts, trousers, shoes), user registration, order total and an SQL script (`prueba2.sql`) |
| `coches/` | Animated car race in PHP and CSS: every page load gives each car a random speed |
| `peliculas.zip` | Film quiz web app in PHP with images and a results page |
| `laberintix.zip` | Maze game in PHP with themed categories, doors and a final boss for each category |
| `python/` | Python programming exercises |
| `algoritmos_veroz.ipynb` | Greedy algorithms: cheapest combination of meat for a stew and the minimum number of fuel vouchers for a 348 km trip |

## How to run

The PHP projects run on any server with PHP (for example XAMPP): copy a folder to the server's web directory
and open it in the browser. The shop also needs a MySQL database created from `tienda/prueba2.sql`.

*Code and comments are written in Spanish.*
